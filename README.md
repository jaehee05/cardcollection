# 콜렉션북 (cardcollection)

포켓몬 카드 콜렉션북 — 보유 카드를 체크하고 콜렉션 가치를 자동 계산하는 웹앱.
관리자가 세트/카드 DB를 직접 업로드하고, 방문자는 자기 보유 상황을 체크할 수 있습니다.

## 주요 기능
- **콜렉션북**: 세트별 카드 그리드. 보유 카드는 컬러, 미보유는 그레이스케일.
- **개수 조정 / 메모**: 카드별 +/−, 직접 입력, 개인 메모.
- **필터/정렬**: 카드타입, 희귀도, 이름 검색, 번호/이름/보유수량/발매일 정렬.
- **일괄 ±1**: 필터링된 카드 전체에 적용.
- **집계현황**: 총 보유 가치(₩), 희귀도/세트별 통계.
- **관리자**: 세트 추가/편집, 카드 DB 엑셀에서 붙여넣기(TSV), 이미지 URL 1번 입력 시 패턴으로 전체 자동 채움.

## 데이터 동기화
- 세트/카드 DB는 **Firestore** (`sets` 컬렉션)에 저장 — 모든 방문자가 같은 DB를 봅니다.
- 사용자별 보유 상태/메모는 **localStorage**에만 저장 — 기기마다 따로.

## 개발

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # 프로덕션 빌드 (dist/)
```

## 배포
Vercel 호스팅. `vercel --prod` 또는 main 브랜치 push로 배포.

Live: https://cardcollection.vercel.app

## Firestore 규칙
`firestore.rules` 가 저장소 루트에 있음. 콘솔에서 "테스트 모드"로 두거나,
Firebase CLI로 배포:

```bash
firebase deploy --only firestore:rules
```

현재는 `sets` 컬렉션 read/write가 모두 공개로 열려있음(MVP). 관리자 인증 도입 시 좁혀야 함.

## 관리자 사용법
1. 상단 탭에서 **관리자** 선택.
2. **새 세트 만들기** → 이름/코드/지역/발매일 입력.
3. **엑셀에서 붙여넣기** 영역에 엑셀/시트 셀 범위를 그대로 paste.
   - 컬럼 순서: `번호 | 이름 | 희귀도 | 타입 | HP | 진화단계 | 시세 | 이미지URL | 일러스트`
   - 첫 행이 헤더면 자동 인식.
4. **이미지 URL 일괄 채우기**: 1번 카드의 imageUrl을 입력하면 URL 안의 숫자 패턴을 인식해 나머지 카드의 URL을 자동 생성.
   - 예: `https://x.com/sv7a/001.png` → `005.png`, `094.png` …

## TSV 컬럼 매핑 참고
| 컬럼 | 허용 표기 |
| --- | --- |
| 희귀도 | `C` `U` `R` `RR` `AR` `SR` `SAR` `UR` 또는 한글명(`커먼` `언커먼` …) |
| 타입 | `풀` `불꽃` `물` `번개` `초` `격투` `악` `강철` `드래곤` `무색` `트레이너` `에너지` (또는 영문 키) |
| 진화단계 | `기본` `1진화` `2진화` `트레이너` `에너지` |
