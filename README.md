# 콜렉션북 (cardcollection)

포켓몬 카드 콜렉션북 — 보유 카드를 체크하고 콜렉션 가치를 자동 계산하는 웹앱.

## 주요 기능
- **콜렉션북**: 세트별 전체 카드 그리드. 보유 카드는 컬러, 미보유는 그레이스케일.
- **개수 조정**: 카드 카드마다 +/− 버튼으로 보유 수량 조정.
- **메모**: 카드별 개인 메모.
- **필터/정렬**: 카드타입, 희귀도, 이름 검색, 번호/이름/보유수량/발매일 정렬.
- **일괄 +1 / −1**: 필터링된 카드 전체에 한꺼번에 적용.
- **집계현황**: 총 보유 가치(₩), 희귀도별·세트별 보유 상황과 가치 합계.
- **localStorage 영속화**: 별도 로그인 없이 바로 사용 가능.

## 개발

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # 프로덕션 빌드 (dist/)
```

## 배포
Vercel 호스팅. main 브랜치 push 시 자동 배포되도록 연결돼 있음.

## 데이터
`src/data/` 에 세트와 카드 정보가 있음. 현재는 「낙원드래고나」 샘플 데이터.
시세 값은 샘플이며 실거래가가 아님.
