# 콜렉션북 (cardcollection)

내가 보유한 포켓몬 카드를 입력하고, 그 카드들로 덱을 짜는 개인용 웹앱.

## 주요 기능
- **내 카드**: 보유 카드를 자유롭게 추가/편집/삭제. 이름·시리즈마크·레귤레이션마크·번호·타입·HP·진화단계·희귀도·이미지URL·보유수량·메모를 기록.
- **검색/필터**: 이름·메모 검색, 시리즈 / 레귤 / 희귀도 / 타입 필터, 보유만 보기, 다양한 정렬.
- **덱**: 보유 카드로 덱 구성. 60장·같은 이름 4장·스탠다드 합법성·보유 수량 초과 여부를 자동 표시. 덱 메모.
- **JSON 백업/복원**: 푸터의 ↓/↑ 버튼으로 전체 데이터를 파일로 내보내고 복원.

## 데이터 저장
- 모든 데이터는 **localStorage**에 저장됩니다 (이 기기 한정).
- 동기화/공유가 필요하면 JSON 백업으로 옮기세요.
- 브라우저 데이터 삭제 시 함께 사라지므로 주기적인 백업 권장.

## 개발

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # 프로덕션 빌드 (dist/)
```

## 배포
Vercel 호스팅. `vercel --prod` 또는 main 브랜치 push로 배포.

Live: https://cardcollection.vercel.app

## 스택
Vite + React 19 + TypeScript + Tailwind v3. 외부 백엔드 없음.
